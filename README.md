# E-Commerce Sales & Customer Analytics using SQL

## Project Overview
This beginner-to-intermediate SQL project analyzes an e-commerce business using MySQL. The goal is to understand sales performance, customer behavior, product performance, and order trends.

## Business Questions
- What is the total revenue generated?
- Which products and categories generate the most revenue?
- Which customers place repeat orders?
- What is the monthly sales trend?
- What is the average order value?
- Which cities contribute the most sales?

## Tools
- MySQL 8.4
- MySQL Workbench
- GitHub

## Database Structure
The database contains five main tables:
- `customers`
- `categories`
- `products`
- `orders`
- `order_items`

## Project Learning Path
1. Database and table creation
2. Sample data insertion
3. Basic filtering and sorting
4. Aggregation and grouping
5. JOIN operations
6. Business analysis queries
7. Advanced SQL concepts

## How to Run
Run the SQL files in this order:
1. `database/01_create_database.sql`
2. `database/02_create_tables.sql`
3. `database/03_insert_data.sql`
4. Query files inside the `queries` folder

## Note
This is a learning project created to practice SQL concepts through a realistic e-commerce dataset.
